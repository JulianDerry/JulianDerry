# Forensic Methodology

Every investigation follows a structured DFIR workflow:

```text
Identification
      ↓
Preservation
      ↓
Acquisition
      ↓
Hash Verification
      ↓
Examination
      ↓
Analysis
      ↓
Correlation
      ↓
Timeline Reconstruction
      ↓
Reporting
```

> **Quality Principle:** Automated tool output is manually validated against the underlying evidence whenever practical.

# Evidence & Reporting Standard

Each case study includes the same professional reporting structure.

| Stage | Included |
|--------|----------|
| Evidence Handling | Acquisition & Chain of Custody |
| Integrity | Hash Verification |
| Examination | Artifact Analysis |
| Correlation | Timeline Reconstruction |
| Findings | What the Evidence Established |
| Limitations | What the Evidence Did **Not** Establish |
| Reporting | Professional Forensic Report |

### Evidence Integrity Checklist

- [x] Evidence acquisition documented
- [x] Chain of custody recorded
- [x] Hash values verified
- [x] Artifact examination performed
- [x] Timeline reconstructed
- [x] Findings supported by evidence
- [x] Limitations explicitly documented
